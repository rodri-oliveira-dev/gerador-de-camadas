# Contribuindo

Obrigado pelo interesse neste projeto.

Este repositório é mantido como **registro histórico** e não está mais em desenvolvimento ativo. O objetivo atual é preservar o código, a documentação e o contexto técnico do projeto, e não evoluí-lo como uma solução .NET moderna.

## Escopo das contribuições

Contribuições relacionadas à preservação do projeto podem ser consideradas, por exemplo:

- correções de documentação;
- melhorias de clareza no README;
- correção de links quebrados;
- ajustes no changelog histórico;
- correções pontuais que ajudem a manter o código compreensível;
- remoção de artefatos acidentais que não tenham valor histórico.

## Fora do escopo

Em geral, não serão aceitas contribuições que tentem transformar o projeto em uma solução atual, incluindo:

- novas funcionalidades;
- reescritas arquiteturais;
- migração para versões modernas do .NET;
- substituição completa das tecnologias originais;
- refatorações extensas apenas para adequação a padrões atuais;
- evolução do projeto para uso em produção.

Essas mudanças apagariam parte do contexto que este repositório pretende preservar.

## Issues e suporte

O projeto não possui suporte ativo.

Issues relacionadas a dúvidas de uso, novas funcionalidades ou problemas de execução em ambientes modernos podem não ser atendidas.

Issues relacionadas à documentação, preservação histórica ou algum problema relevante no próprio repositório são bem-vindas.

## Pull Requests

Antes de abrir uma Pull Request, considere se a mudança contribui para a preservação e compreensão do projeto sem descaracterizar seu contexto original.

Prefira alterações pequenas, objetivas e acompanhadas de uma descrição clara do motivo da mudança.

## Contexto histórico

O código deste repositório reflete decisões, ferramentas e práticas utilizadas no período em que foi desenvolvido. Algumas delas não representam as práticas que eu utilizaria atualmente.

Isso é intencional.

O propósito deste repositório é preservar **o projeto como parte de uma trajetória profissional**, e não apresentar sua arquitetura como referência para novos sistemas.
